Відкрийте index.html у браузері або завантажте index.html, questions.js, game.js до кореня репозиторію GitHub. Settings → Pages → Deploy from a branch → main / (root) → Save. Відкрийте опубліковане посилання.

1–6 учасників за одним пристроєм. 60 карток з вибором відповіді, три рівні, контрольні брами 5/15/23, фінал із трьох питань. Прогрес локальний, без сервера. Для сертифіката оберіть «Друк / зберегти PDF» і в діалозі браузера — збереження PDF. Оцінка рекомендована, за зваженою правильністю відповідей; підказки обліковуються окремо. Завершення уроку доступне між ходами. Клас зазначається в сертифікаті; банк завдань спільний, складність обирається вручну. Використовуйте псевдоніми на спільних пристроях. Локальне збереження не є захищеним журналом оцінок.
